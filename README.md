# Использование Apache Spark под управлением YARN для чтения, трансформации и записи данных

## Подготовка к выполнению

Все команды ниже предполагают запуск из корневого каталога работы - каталога, в котором находятся `scripts/`, `src/` и `sql/`.

На виртуальной машине этот каталог расположен по пути `~/spark`. 

Перед запуском скриптов установите право на исполнение. Это необходимо, поскольку при переносе файлов через Git или между файловыми системами права доступа могут отличаться:

```bash
chmod +x scripts/*.sh
```

Работа предполагает наличие ранее развёрнутого кластера Hadoop с YARN и HDFS. В качестве окружения используются Java 17, Apache Hadoop 3.5.0, Apache Spark 3.5.3 и Apache Hive 4.1.0.

## Предварительный этап. Установка и настройка Spark

Установка Spark выполняется скриптом:

```bash
./scripts/setup_spark.sh
```

В `scripts/spark_env.sh` задаются основные параметры окружения:

- `SPARK_HOME` - каталог установки Spark;
- `HADOOP_CONF_DIR` и `YARN_CONF_DIR` - расположение конфигурации Hadoop;
- `SPARK_DIST_CLASSPATH` - классы и библиотеки Hadoop, необходимые Spark.

Настройка окружения выполняется скриптом scripts/spark_env.sh. Чтобы применить заданные переменные в текущем терминале, выполните из корня работы:

```bash
source ./scripts/spark_env.sh
```

Настройка действует только в текущем терминале. При открытии нового терминала команду необходимо выполнить повторно.

## Этап 1. Запуск Spark под управлением YARN

Spark-приложения запускаются с помощью `spark-submit` через скрипт `scripts/run_session.sh`:

```bash
./scripts/run_session.sh src/start_spark_session.py
```

Скрипт передаёт Spark параметры:

- `--master yarn` - использование YARN в качестве менеджера ресурсов;
- `--deploy-mode client` - запуск драйвера на узле, с которого отправлено приложение.

YARN распределяет вычислительные ресурсы, а SparkSession предоставляет интерфейс для обработки данных.

## Этап 2. Подключение к HDFS

Для проверки подключения к распределённой файловой системе запускается приложение:

```bash
./scripts/hdfs_connection.sh
```

Оно выводит информацию о версии Spark, режиме работы и содержимом корневого каталога HDFS. Это позволяет убедиться, что Spark запускается и может обращаться к распределённой файловой системе.

## Этап 3. Чтение данных из HDFS

Перед чтением необходимо подготовить исходные данные. Скрипт загружает набор данных Palmer Penguins в формате CSV и размещает его в HDFS:

```bash
./scripts/prepare_dataset.sh
```

Исходный файл размещается по пути:

```text
/user/team/spark-course/input/penguins.csv
```

Адрес NameNode: `hdfs://team-38-nn:9000`.

Для чтения используется `src/read_hdfs.py`, запускаемый через `scripts/read_hdfs.sh`. Формат задаётся параметром: `csv`, `json`, `parquet` или `text`.

Пример чтения исходного CSV:

```bash
./scripts/read_hdfs.sh \
  hdfs://team-38-nn:9000/user/team/spark-course/input/penguins.csv \
  csv
```

Скрипт создаёт SparkSession, считывает файл средствами Spark и выводит информацию о данных. Исходный файл при этом читается из HDFS, а не из локальной файловой системы.

## Этап 4. Трансформация данных

Запуск обработки:

```bash
./scripts/transform_data.sh
```

В `src/penguins_data.py` реализованы загрузка данных, преобразование типов столбцов и обработка пропусков. Числовые признаки приводятся к подходящим типам, а строки с отсутствующими значениями в необходимых полях исключаются.

В `src/transform_data.py` выполняются SQL-запросы из каталога `sql/`:

- `filter_and_sort.sql` - фильтрация по массе тела, полу и длине плавника, сортировка результатов;
- `species_statistics.sql` - группировка по виду и полу, вычисление количества записей и средних значений.

Дополнительно рассчитывается масса тела в килограммах. Преобразования выполняются средствами Spark SQL и DataFrame API.

## Этап 5. Партиционирование при записи

Запись данных с партиционированием выполняется командой:

```bash
./scripts/partition_data.sh
```

Скрипт `src/partition_data.py` повторно использует подготовку данных и SQL-фильтрацию, после чего записывает результат в формате Parquet с разделением по столбцу `species`.

Каталог результата в HDFS:

```text
/user/team/spark-course/output/penguins_partitioned
```

Партиционирование создаёт отдельные каталоги для значений столбца `species`. Это позволяет Spark эффективнее читать данные при запросах с фильтрацией по соответствующему признаку.


## Этап 6. Сохранение преобразованных данных в таблицу

Сохранение данных в таблицу выполняется командой:

```bash
./scripts/save_table.sh
```

Скрипт `src/save_table.py` читает ранее сохранённые данные Parquet и сохраняет их как таблицу `penguins_filtered`, указывая расположение данных в HDFS.

Каталог таблицы:

```text
/user/team/spark-course/tables/penguins_filtered
```

На этом этапе данные представлены не только файлами Parquet, но и таблицей, доступной для запросов через Spark SQL. Далее этот же каталог используется для проверки чтения через Hive.

## Промежуточный этап. Установка и настройка Hive

Для проверки совместимости сохранённой таблицы со стандартным клиентом Hive используется Apache Hive 4.1.0.

Установка выполняется командой:

```bash
./scripts/setup_hive.sh
```

Скрипт `scripts/register_hive_table.sh` и SQL-файл `sql/register_penguins_filtered.sql` обеспечивают инициализацию схемы Metastore при необходимости, регистрацию внешней таблицы и выполнение контрольного запроса.

Таблица `penguins_filtered` регистрируется как внешняя таблица формата Parquet и ссылается на каталог, созданный на предыдущем этапе. Повторное копирование данных не требуется.

В текущем окружении для выполнения запроса используется движок MapReduce. Скрипт также подключает библиотеку `commons-collections-3.2.2.jar`, необходимую для запуска задачи в данном окружении.

## Этап 7. Проверка чтения данных клиентом Hive

Запуск проверки:

```bash
./scripts/register_hive_table.sh
```

После регистрации внешней таблицы выполняется запрос, который группирует данные по виду пингвина, подсчитывает количество записей и сортирует результат по виду.

Ожидаемый результат:

| Вид | Количество записей |
|---|---:|
| Adelie | 66 |
| Chinstrap | 45 |
| Gentoo | 117 |

Общее количество записей - 228.

Результат подтверждает, что данные, сохранённые средствами Spark в формате Parquet, доступны для чтения через Hive. Полный журнал выполнения сохраняется в `logs/register_hive_table.log`.

## Последовательность выполнения работы

При последовательном выполнении этапов используйте команды из корневого каталога работы:

```bash
chmod +x scripts/*.sh

./scripts/setup_spark.sh
source ./scripts/spark_env.sh

./scripts/run_session.sh src/start_spark_session.py

./scripts/hdfs_connection.sh

./scripts/prepare_dataset.sh
./scripts/read_hdfs.sh \
  hdfs://team-38-nn:9000/user/team/spark-course/input/penguins.csv \
  csv

./scripts/transform_data.sh
./scripts/partition_data.sh
./scripts/save_table.sh

./scripts/setup_hive.sh
./scripts/register_hive_table.sh
```

Установка Hadoop и развёртывание YARN/HDFS в эту последовательность не включены, поскольку они выполнялись в предыдущих заданиях.
