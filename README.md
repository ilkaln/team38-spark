# team38-spark


## Установка Spark

Для установки используется Apache Spark 3.5.3 без встроенных Hadoop-библиотек. Это позволяет использовать библиотеки Hadoop, доступные в окружении кластера.

Перейдите в каталог проекта:

```bash
cd ~/spark
```

Запустите установочный скрипт:

```bash
chmod +x scripts/setup_spark.sh
./scripts/setup_spark.sh
```

Скрипт скачивает архив Spark, проверяет его контрольную сумму, распаковывает файлы в каталог `$HOME/opt` и удаляет скачанные архивы.

После установки Spark находится по пути:

```text
$HOME/opt/spark-3.5.3-bin-without-hadoop
```

Установку достаточно выполнить один раз для данного пользователя и машины.

## Настройка окружения

После установки необходимо загрузить переменные окружения. Для этого используется отдельный файл `scripts/spark_env.sh`.

Выполните команду из корня проекта:

```bash
source scripts/spark_env.sh
```

Файл задаёт следующие переменные:

- `SPARK_HOME` — путь к установленному Spark.
- `PATH` — добавляет каталог с исполняемыми файлами Spark.
- `HADOOP_CONF_DIR` — путь к конфигурации Hadoop.
- `YARN_CONF_DIR` — путь к конфигурации YARN.
- `SPARK_DIST_CLASSPATH` — classpath с библиотеками Hadoop, полученный через `hadoop classpath`.

**Важно:** файл необходимо подключать через `source`, а не запускать как отдельный скрипт. Переменные будут доступны в текущем терминале.

При открытии нового SSH-сеанса настройку необходимо повторить. При желании её можно подключить автоматически через `~/.bashrc`.

## Проверка установки

После загрузки переменных выполните:

```bash
spark-submit --version
```

Команда должна вывести версию Spark и используемую версию Java.
