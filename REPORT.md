# Отчёт о выполнении домашнего задания № 4

## Использование Apache Spark под управлением YARN для чтения, трансформации и записи данных

## 1. Цель работы

Цель работы - освоить использование Apache Spark под управлением YARN для чтения данных из HDFS, их преобразования, партиционирования и сохранения в таблицу, а также проверить возможность чтения полученных данных стандартным клиентом Hive.

В качестве исходных данных использован набор Palmer Penguins в формате CSV.

## 2. Среда выполнения

Работа выполнена на узле `team-38-en` с использованием ранее развёрнутого кластера Hadoop.

Spark-приложения запускались через `spark-submit` с параметрами `--master yarn` и `--deploy-mode client`.

## 3. Выполнение задания

### Этап 1. Запуск сессии Apache Spark под управлением YARN

Для запуска Spark-приложения использован скрипт `scripts/run_session.sh`:

```bash
./scripts/run_session.sh src/start_spark_session.py
```

Скрипт запускает приложение через `spark-submit`, указывая YARN в качестве менеджера ресурсов и клиентский режим размещения драйвера.

В результате выполнения получены следующие значения:

```text
Spark version: 3.5.3
Spark master: yarn
Application ID: application_1792046452208_0027
```

**Результат:** приложение Spark успешно запущено под управлением YARN. Версия Spark и режим работы подтверждены выводом приложения.

### Этап 2. Подключение к кластеру HDFS

Для проверки подключения использован скрипт:

```bash
./scripts/hdfs_connection.sh
```

Скрипт запускает Spark-приложение, проверяет доступность файловой системы и выводит содержимое её корневого каталога.

Получен следующий результат:

```text
Spark version: 3.5.3
Spark master: yarn
Application ID: application_1792046452208_0028
Connected filesystem: hdfs://team-38-nn:9000
Root directory contents:
  DIR  hdfs://team-38-nn:9000/mr-history
  DIR  hdfs://team-38-nn:9000/tmp
  DIR  hdfs://team-38-nn:9000/user
HDFS connection check: SUCCESS
```

**Результат:** подтверждено подключение Spark к HDFS по адресу `hdfs://team-38-nn:9000` и возможность получения информации о содержимом файловой системы.

### Этап 3. Чтение данных из HDFS

Для подготовки исходных данных выполнена команда:

```bash
./scripts/prepare_dataset.sh
```

Скрипт загрузил CSV-файл набора Palmer Penguins и разместил его в HDFS по пути:

```text
/user/team/spark-course/input/penguins.csv
```

После этого данные прочитаны с помощью скрипта `scripts/read_hdfs.sh`:

```bash
./scripts/read_hdfs.sh \
  hdfs://team-38-nn:9000/user/team/spark-course/input/penguins.csv \
  csv
```

Приложение успешно прочитало файл, вывело схему данных и первые 20 строк. При чтении CSV названия столбцов были определены как заголовки. Числовые поля, кроме `year`, на данном этапе представлены преимущественно строковыми типами и преобразуются на следующем этапе обработки.

**Результат:** чтение исходных данных из HDFS средствами Spark выполнено успешно.

### Этап 4. Трансформация данных

Трансформации выполнены командой:

```bash
./scripts/transform_data.sh
```

Обработка реализована с использованием Python, Spark DataFrame API и Spark SQL.

В ходе обработки выполнены следующие операции:

- преобразование типов столбцов;
- обработка пропущенных значений и исключение строк, в которых отсутствуют необходимые для дальнейшей обработки данные;
- фильтрация записей по массе тела, полу и длине плавника;
- вычисление массы тела в килограммах;
- сортировка отобранных записей;
- группировка данных по виду и полу;
- вычисление количества записей, средней массы тела и средней длины плавника.

Для фильтрации и сортировки используется запрос `filter_and_sort.sql`, для вычисления статистики - `species_statistics.sql`.

В результате вычисления статистических показателей получена следующая таблица:

| Вид | Пол | Количество | Средняя масса, кг | Средняя длина плавника, мм |
|---|---|---:|---:|---:|
| Adelie | female | 12 | 3,675 | 193,5 |
| Adelie | male | 54 | 4,111 | 195,4 |
| Chinstrap | female | 15 | 3,722 | 194,9 |
| Chinstrap | male | 30 | 4,018 | 200,8 |
| Gentoo | female | 58 | 4,680 | 212,7 |
| Gentoo | male | 59 | 5,461 | 221,4 |

**Результат:** трансформации и SQL-запросы выполнены успешно. Получены отфильтрованные данные и статистические показатели по видам и полу.

### Этап 5. Партиционирование при сохранении данных

Запись данных с партиционированием выполнена командой:

```bash
./scripts/partition_data.sh
```

Данные сохранены в формате Parquet по пути:

```text
/user/team/spark-course/output/penguins_partitioned
```

В качестве ключа партиционирования использован столбец `species`.

При проверке каталога в HDFS обнаружены три каталога партиций:

```text
species=Adelie
species=Chinstrap
species=Gentoo
```

Также присутствует служебный файл `_SUCCESS`, свидетельствующий об успешном завершении операции записи.

**Результат:** преобразованные данные записаны в Parquet с разделением на партиции по виду пингвина. Наличие отдельных каталогов подтверждает применение партиционирования.

### Этап 6. Сохранение преобразованных данных в таблицу

Сохранение выполнено скриптом:

```bash
./scripts/save_table.sh
```

На основе ранее сохранённых данных Parquet создана таблица `penguins_filtered`. Её данные расположены в HDFS:

```text
/user/team/spark-course/tables/penguins_filtered
```

Схема созданной таблицы:

| Столбец | Тип |
|---|---|
| `island` | string |
| `sex` | string |
| `flipper_length_mm` | integer |
| `body_mass_g` | integer |
| `body_mass_kg` | decimal(15,3) |
| `species` | string |

Для проверки содержимого выполнена группировка по виду. Получены следующие результаты:

| Вид | Количество записей |
|---|---:|
| Adelie | 66 |
| Chinstrap | 45 |
| Gentoo | 117 |
| **Всего** | **228** |

**Результат:** таблица `penguins_filtered` создана, схема определена, данные доступны для запросов средствами Spark SQL. Общее количество записей составляет 228.

### Этап 7. Проверка чтения данных стандартным клиентом Hive

Для проверки совместимости данных с Hive установлена и проверена Apache Hive 4.1.0.

Регистрация внешней таблицы и выполнение контрольного SQL-запроса произведены командой:

```bash
./scripts/register_hive_table.sh
```

Таблица `penguins_filtered` зарегистрирована как внешняя таблица формата Parquet, указывающая на каталог данных, созданный на предыдущем этапе. Повторное копирование файлов не выполнялось.

В текущем окружении запрос исполняется с использованием движка MapReduce. Для работы задачи дополнительно подключается библиотека `commons-collections-3.2.2.jar`.

После регистрации выполнен запрос, группирующий данные по виду и подсчитывающий количество записей. Получен результат:

| Вид | Количество записей |
|---|---:|
| Adelie | 66 |
| Chinstrap | 45 |
| Gentoo | 117 |

Вывод скрипта:

```text
Checking Hive Metastore schema
Metastore schema is initialized
Registering the penguins table and running the query

Query result:
|  species   | penguin_count  |
| Adelie     | 66             |
| Chinstrap  | 45             |
| Gentoo     | 117            |

Hive stage completed successfully
```

В журнале присутствуют предупреждения Hive об отсутствии статистики оптимизатора для таблицы. Они не помешали выполнению контрольного запроса.

Полный журнал сохранён в `logs/register_hive_table.log`.

**Результат:** Hive успешно зарегистрировал внешнюю таблицу и прочитал данные, ранее сохранённые средствами Spark. Результаты подсчёта совпадают с результатами предыдущего этапа.

## 4. Итоги работы

В ходе выполнения домашнего задания реализованы и проверены все семь требуемых операций:

1. Запуск Spark-приложения под управлением YARN.
2. Подключение Spark к HDFS.
3. Чтение исходных данных из HDFS.
4. Трансформация данных средствами DataFrame API и Spark SQL.
5. Сохранение данных в формате Parquet с партиционированием по `species`.
6. Сохранение преобразованных данных в таблицу `penguins_filtered`.
7. Проверка чтения таблицы стандартным клиентом Hive.

Таким образом, продемонстрирован полный цикл работы с данными: от чтения исходного файла из HDFS до преобразования, партиционированной записи и последующего чтения через Hive.
